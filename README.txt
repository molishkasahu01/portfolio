MOLISHKA SAHU — PORTFOLIO

Files: index.html, styles.css, script.js, Molishka_Sahu_Resume.pdf.

QUICK START
Extract the ZIP and open index.html in a modern browser. Keep all four files together.
Optional: run python -m http.server 8000 in the extracted folder, then open http://localhost:8000.
For hosting, upload the entire folder to any static website host. No build tools or packages are needed.

FEATURES
Responsive layout, project filters, accessible project-detail dialogs, light/dark theme, email copying, email contact link, and download of the supplied original résumé.
Google Fonts requires an internet connection; local Arial and Georgia fallbacks work offline.
Clipboard permissions vary by browser; HTTPS or localhost is recommended. If copying is blocked, the address is shown for manual copying.

CONTENT & DESIGN
Original design inspired by the reference site's introduction and project-case-study structure, not an exact reproduction. Direct fetching of the reference failed, so visual fidelity was not verified.
Project previews are illustrative HTML/CSS mockups, not real screenshots or functioning project dashboards.
AgentGuard is described as designed; NeuroTrace is explicitly proposed. No employment, degree, graduation year, GitHub link, LinkedIn link, or project URLs were invented.
The contact action opens an email client; it is not a backend contact form.
The supplied résumé is included unchanged. Replace the PDF with the same filename to update it.

CUSTOMIZE
Edit text in index.html. Edit expanded project details in the projects object in script.js. Edit colors via the CSS variables at the top of styles.css.
Replace preview mockups with your own screenshots and add verified live project links when available.
Before publishing, review the content and check mobile layouts, keyboard navigation, project dialogs, filtering, email action, theme toggle, and résumé download in your browser.
